# ADR-0006: 로컬 웹 제품으로 전환하고 네이티브 프로토타입을 폐기한다

- 상태: 승인됨
- 날짜: 2026-08-15

## 맥락

무료 서명 네이티브 앱은 일상 운영 경로로 적합하지 않았다. #7에서 iPhone
로컬 파일 Outbox, Mac 로컬 서버, SQLite와 Tailscale 내부 웹의 유실 방지,
멱등성 및 재시작 복구 가능성을 검증했다.

기존 iOS 앱은 완성된 제품이 아니라 기술 검증용 프로토타입이었다. 이를
계속 현역으로 두면 SwiftData와 앱 빌드 호환성이 새 제품의 불필요한 설계
제약이 된다.

## 결정

- 사용자 기능의 주 경로를 iPhone Outbox와 Mac 로컬 웹으로 전환한다.
- 앞으로 수집하는 거래는 Mac SQLite를 기준 저장소로 사용한다.
- 네이티브 앱 소스, SwiftData 구현과 전용 테스트를 저장소에서 제거한다.
- 기존 SwiftData 자료를 이전하지 않는다.
- `CherryPickerCore`의 재사용 가능한 파서와 순수 정책은 유지한다.
- 세부 스키마와 운영 정책은 얇은 제품 흐름을 구현한 뒤 필요한 시점에 정한다.

저장소 정리는 사용자의 기기에 설치된 앱이나 기존 SwiftData 파일을
자동으로 찾거나 삭제하지 않는다.

## 결과

- 새 제품은 네이티브 앱 호환성과 SwiftData migration의 제약을 받지 않는다.
- Core, Server와 로컬 웹이 현역 제품 경계가 된다.
- 과거 프로토타입은 Git 기록으로 복원할 수 있지만 빌드와 테스트 대상은 아니다.
- 자동 백업과 장기 SQLite migration은 실제 운영 데이터의 필요성이 생길 때
  별도 결정한다.
