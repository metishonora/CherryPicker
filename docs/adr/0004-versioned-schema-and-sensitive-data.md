# ADR-0004: SwiftData 버전 스키마 — 대체됨

- 상태: ADR-0006으로 대체됨
- 날짜: 2026-08-15

이 ADR의 SwiftData migration 결정은 폐기된 네이티브 프로토타입만을 위한
것이었다. 기존 SwiftData 자료는 새 SQLite 제품으로 이전하지 않으며 현재
제품의 스키마 결정에 이 ADR을 사용하지 않는다.

원문을 기본 화면과 로그에서 숨긴다는 개인정보 원칙은
[`PRODUCT_ARCHITECTURE.md`](../PRODUCT_ARCHITECTURE.md)에서 계속 유지한다.
