# Issue #9 완료 보고

- 이슈: `MG 더나은 체크카드 정의와 실제 문자 수집`
- 완료 판단일: 2026-08-19
- 제품 경로: iPhone 로컬 파일 Outbox → Tailscale 내부 경로 → `CherryPickerLocalServer` → SQLite → 로컬 웹

## 완료 결과

### 카드 정의

- `MG 더나은 체크카드` 카드 종류가 안정적인 식별 코드, 문자 식별 규칙,
  승인·승인취소 파서, 기본 실적 목표와 실제 혜택 정책을 함께 소유한다.
- 보유 카드 instance는 카드 종류를 참조하면서 표시 이름, 끝 네 자리와
  사용자 조정 실적 목표를 별도로 보존한다.
- 예시 혜택은 제품 화면에서 제거했고, 확인된 세 가지 할인캐시백 혜택과
  거래 최소금액·월 한도·제외 정책을 계산 경계에 연결했다.

### 실제 수집 경로

- 실제 승인 문자를 다시 전달한 시험에서 iPhone 자동화가 이벤트를 제품
  서버로 전송했고 canonical 거래와 수신 기록이 생성됐다.
- 파싱 성공 거래는 카드 끝 네 자리, 금액, 거래 일시와 가맹점 필드가 전달한
  문자와 일치했으며 미확인 거래 및 거래 검토 화면에 표시됐다.
- 파싱 실패 입력도 수집 성공으로 처리되어 거래와 수신 기록이 남았다.
  원문은 SQLite에 보존되지만 기본 웹, 로그와 이 보고서에는 노출하지 않는다.
- 서버 확인 전 Outbox 파일을 유지하고 `accepted` 또는 `duplicate` 응답을
  확인한 파일만 제거하는 단축어 경계를 유지했다. 동일 event ID 재전송은
  기존 canonical 거래를 반환하며 중복 거래를 만들지 않는다.
- 실제 승인취소 문자는 수신 기회가 없었으므로 기존 개인정보 제거 fixture와
  회귀 테스트를 완료 근거로 유지한다.

## 운영 서버 확인

2026-08-19 확인 시점의 개인정보 없는 운영 상태는 다음과 같다.

- LaunchAgent 설치 구성과 binary·SQLite 경로의 일치 검증 통과
- loopback health 응답 `ok`
- 승인된 Tailscale 내부 웹 경로 접근 가능
- SQLite `quick_check` 결과 `ok`
- canonical 거래 3건, 수신 기록 3건
- 파싱 상태 집계: 성공 1건, 실패 보존 2건
- 최신 제품 화면에서 카드 대시보드, 거래 목록과 거래 검토 경로 확인

Mac 재시작 뒤에는 `Scripts/LocalServer/recover-launch-agent.sh --check`로
설치 상태를 변경 없이 검사할 수 있다. 복구가 필요하면 같은 스크립트를
인자 없이 실행한다. 이 경로는 SQLite, 로그와 Tailscale Serve를 변경하지
않는다. 자세한 절차는 `docs/LOCAL_SERVER_OPERATIONS.md`에 기록했다.
